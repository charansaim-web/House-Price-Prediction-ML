# 🏠 House Price Prediction using Machine Learning

## 📌 Project Overview
This project predicts house prices using a Machine Learning model built with Linear Regression. It includes data preprocessing, model training, evaluation, and a Flask-based web application that allows users to enter house details and receive real-time price predictions.

---

## 🎯 Objectives
- Predict house prices based on property features.
- Perform data preprocessing and feature engineering.
- Train and evaluate a Linear Regression model.
- Deploy the trained model using a Flask web application.

---

## 🚀 Features
- Data preprocessing and cleaning
- Feature engineering
- Linear Regression model
- Real-time house price prediction
- Interactive Flask web application

## ▶️ How to Run

1. Clone the repository

```
git clone https://github.com/charansaim-web/House-Price-Prediction-ML.git
```

2. Install dependencies

```
pip install -r requirements.txt
```

3. Run the Flask application

```
python app.py
```

4. Open your browser and visit

```
http://127.0.0.1:5000/
```
